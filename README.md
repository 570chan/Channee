# 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/your-username/Channee.git
```

Open the project

```text
index.html
```

Or run it with VS Code **Live Server**.

---

# 🎨 Customization

You can easily replace:

- **Avatar**

```
assets/avatar.jpg
```

- or replace the video inside

```
assets/*.mp4
```

- **Profile Information**

Edit

```
index.html
```

- **Style**

Edit

```
style.css
```

- **Interactive Effects**

Edit

```
script.js
```
